# creative-portfolio-2026

张语酌创意作品集 — 文学写作、AI 产品、AIGC 影视、广告营销、配音与影像创作精选作品集。

纯静态 HTML/CSS/JS 站点，部署于 GitHub Pages。

## 结构

```
├── index.html          # 概览首页（含自媒体矩阵）
├── literature.html     # 01 · 文学作品
├── ai-products.html    # 02 · AI产品
├── aigc-films.html     # 03 · AIGC影视
├── advertising.html    # 04 · 广告营销
├── dubbing.html        # 05 · 配音作品
├── other-films.html    # 06 · 其他影视
├── css/style.css       # 样式表
├── js/main.js          # 滚动动画
├── images/             # 优化后的图片资源
└── .nojekyll           # 禁用 Jekyll 处理
```
